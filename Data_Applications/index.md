# Data Application

This section contains the data applications discussed in the TransMap paper. Below, we outline key components for analyzing data using the `transmap` R package and related methodologies.

## 1. Vignettes for `transmap`

The [tutorial website](https://xueweic.github.io/transmap/) describes input data formats, example workflows for TransMap-eGene, TransMap-local and TransMap-global, and interpretation of results.

## 2. Related resources

- [colocboost](https://github.com/StatFunGen/colocboost): multi-trait colocalization used to integrate *cis*-eQTL, *trans*-QTL, biomarker-QTL and GWAS signals.
- [xQTL protocols](https://statfungen.github.io/xqtl-protocol/): bioinformatics pipelines for fine-mapping, colocalization and S-LDSC enrichment analyses.
